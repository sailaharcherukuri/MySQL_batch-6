What is data?
--------------
Raw facts or figures without context
example :101, lahar, vizag , 20000

What is field?
--------------
smallest unit of data in database(column/attribute)
example: 9101, 'sunny', 50000)

What is record ?
---------------
Collection of related fields(row/tuple)
ex = (101, 'sunny', 50000)

What is data base ?
Organized collection of related records stored together.
ex = an employee database containing all employee records.

Client-server architecture
------------------------
Client:
-------
 The roe of the client in client server architecture is to send request to the server and to get response from the server.

server:
-------
The role of the server in client server architecture is to receive requests from the client, If the request is valid it will generate a response, we can handover hat response to the client, If the client request is not a valid request , It will raise some error status codes.

Protocol:
---------
It has some rules and regulations. The role of the protocol in client-server architecture is to send request from client to server.

SQL(Structured Query Language)
------------------------------
-->  structured query language  is a standardized programming language specially designed for managing and manipulating relational databases. It provides a declarative syntax that allows users to define what data they wanted to retrieve, insert, update or delete without specifying exactly how database should execute these operations.

DML (Data Manipulation Language)
----------------------------------
It manages data stored within database objects(insert, update, delete)

DCL( Data Control Language)
----------------------------

TCL(Transaction Control Language)
---------------------------------
It manages transactions to maintain data integrity.
